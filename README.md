# Concrete Strength Prediction

Цей проєкт демонструє прогнозування міцності бетону за допомогою нейронної мережі на основі набору даних про склад суміші та вік твердіння бетону.

## Що міститься в проєкті

- [hw04.ipynb](hw04.ipynb) — основний блокнот з аналізом даних, підготовкою ознак, навчанням моделі та оцінкою якості.
- [ConcreteStrengthData.csv](ConcreteStrengthData.csv) — датасет з характеристиками бетону та цільовою змінною `Strength`.

## Задача

Передбачити значення міцності бетону (MPa) на основі таких параметрів:

- вміст цементу
- шлак
- зола
- вода
- суперпластифікатор
- крупний та дрібний заповнювачі
- вік бетону

## Технології

- Python
- pandas
- NumPy
- matplotlib
- seaborn
- scikit-learn
- PyTorch

## Як запустити

1. Відкрийте проєкт у VS Code або Jupyter Notebook.
2. Переконайтеся, що встановлені необхідні бібліотеки:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn torch
```

3. Відкрийте [hw04.ipynb](hw04.ipynb) і запустіть комірки по порядку.

## Примітка

Проєкт призначений для навчального застосування і показує базовий workflow для задачі регресії: завантаження даних, попередня обробка, розподіл на тренувальний та тестовий набори, навчання нейронної мережі та оцінка результатів.
